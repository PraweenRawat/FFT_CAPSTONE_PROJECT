System Architecture & Core Platform Workflows
Retailer Workflow (Buyer)
✔ Hyper-Local Discovery
Filter commodities by distance (<5km, 10km, 15km+) from verified mandi mills.
✔ APMC Price Spotlight
Real-time savings benchmarked directly against official APMC Mandi rates (-12.8% savings).
✔ Source Cart & Tracking
Bulk purchase with minimum order quantities and track status (Pending, Dispatched, Delivered).
✔ Store Profile Manager
Control delivery radius, accepted payment modes (COD, NEFT, Card), and store licenses.
Security & Backend Engine
⚡ Stateless JWT Auth
Secure bearer token generation with 7-day expiration and tamper-proof user claims.
⚡ Dual-Mode Persistence
Seamless fallback between live MongoDB Atlas and resilient in-memory stores (100% uptime).
⚡ Strict Role Barrier
Prevents retailers from listing stock and wholesalers from placing orders.
⚡ Live Aggregation Engine
Calculates live metrics from actual database order records rather than static hardcoding.
Wholesaler Workflow (Seller)
✔ Live Revenue & KPIs
Calculates month revenue from eligible orders (₹12.4L) and active connected retailers.
✔ Inline Price Mutation
Directly edit SKU base prices on inventory cards with immediate backend persistence.
✔ Stock Depletion Alerts
Automatic triggers identifying low-stock inventory (threshold ≤ 10 units).
✔ Order Fulfilment Queue
Prioritized fulfillment table displaying buyer identity, quantity, and settlement values.

Project Analysis: Advantages, Limitations & Roadmap
Key Advantages
★ Direct Disintermediation
Eliminates 12–18% middleman commission markups between mills and shops.
★ Zero Ghost Inventory
Real-time stock reservation prevents cancelled orders and stockouts.
★ Transparent Price Discovery
Live APMC benchmark comparison provides fair pricing visibility.
★ Resilient Dual Engine
In-memory fallback guarantees 100% platform uptime during database downtime.
Current Limitations
▲ Active Internet Dependency
Live inventory counts and rate updates require continuous connectivity.
▲ Local Geofence Boundaries
Logistics radius currently optimized for localized mandi hubs (<15–20 km).
▲ Single Currency Ecosystem
Transactions are optimized exclusively for Indian Rupees (INR) and GSTIN formats.
▲ Manual High-Value Settlement
High-value bank transfers currently require manual invoice reconciliation.
Future Enhancements
🚀 AI Predictive Procurement
ML forecasting of mandi price trends and automated Kirana stock replenishment.
🚀 Automated e-Way Bills
Instant GST e-Way bill and tax invoice generation upon order dispatch.
🚀 Integrated Escrow Gateway
Milestone-based digital payment holding until delivery confirmation by retailer.
🚀 Vernacular Voice Search
Multilingual voice search (Hindi, Kannada, Telugu, Marathi) for local traders.
